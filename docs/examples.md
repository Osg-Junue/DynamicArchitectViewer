# Examples

The diagrams in [`examples/`](../examples/), each played as the animated SVG that the extension exports from it. In VS Code, **DynamicArchitectViewer: New Diagram from Sample Template...** starts a new file from any of them.

## Infrastructure: redundant web stack and database failover

CDN, load balancer, API, Redis cache and primary/standby databases, with normal traffic and a failover. Source: [`01-infra-ha-failover.dav`](../examples/01-infra-ha-failover.dav)

![A request passing the edge, a cache hit, a write with replication, and a database failover](media/examples/01-infra-ha-failover.svg)

## Screen flow with API calls: sign-in to checkout

Screen transitions together with the backend calls behind them. Source: [`02-screen-flow-checkout.dav`](../examples/02-screen-flow-checkout.dav)

![Signing in, adding to the cart, charging the card and showing the confirmation](media/examples/02-screen-flow-checkout.svg)

## Microservices: event-driven async pipeline

A queue, a worker and object storage for slow background jobs. Source: [`03-event-driven-async.dav`](../examples/03-event-driven-async.dav)

![A report job that is accepted, generated by a worker and downloaded with a signed URL](media/examples/03-event-driven-async.svg)

## Large system: zero-trust payments and AI fraud detection

A long flow across five zones, with a fraud case that rolls back. Source: [`04-enterprise-zero-trust-payment.dav`](../examples/04-enterprise-zero-trust-payment.dav)

![A payment crossing five zones, and a fraud alert that rolls it back](media/examples/04-enterprise-zero-trust-payment.svg)

## Sequence: payment retries and async delivery

Rate limiting, retries with backoff, and a dead letter queue, with icons on packets. Source: [`05-sequence-payment-retry.dav`](../examples/05-sequence-payment-retry.dav)

![An order whose payment fails, is retried twice and succeeds, and an event that ends in the dead letter queue](media/examples/05-sequence-payment-retry.svg)

## Office LAN: site-to-site VPN and link failover

Switches, Wi-Fi, a printer and a file server, with a VPN and failover to LTE. Source: [`06-lan-office-network.dav`](../examples/06-lan-office-network.dav)

![Traffic inside an office network, over a VPN, and over LTE when the main link fails](media/examples/06-lan-office-network.svg)

How this extension turns a `.dav` file into a live preview, a standalone HTML file and an animated SVG. Source: [`07-dynamic-architect-viewer.dav`](../examples/07-dynamic-architect-viewer.dav)
